# 新增个人参考：版式学习记录

参考文件均只读检查，未改动或上传。已读取13页 Salvinia、19页大挑、30页创新创业稿的对象/文本结构，并渲染目检每套3张代表页。其余页面未逐页视觉审核。渲染器可能无法完整保留特殊字体与嵌入对象。

## 可复用设计规则

1. Salvinia：证据驱动的叙事，宏观照片与机制小图成对，阶段标题直接说明作用。用于文献精读的首要参照。不同页面按现象对比、机制分步、实验验证改变布局。
2. 大挑：标题下用一句话说明本页问题；表征图与结论并排互证。用于科研项目中的“材料—表征—性能”页。借鉴证据与解释紧邻，不照搬字体混用和密集段落。
3. 创新创业：左右交错的图文带、主次清楚的证据块与章节组织。用于成果、应用和项目汇报，不把商业页的口号或未经验证的优势带进论文汇报。

## 应用于 MFI 三页的规则

- 背景：问题递进与主机制图，不强制三栏。
- 制备：顶部横向步骤，下方两组证据与解释紧邻，放大截面EDS，避免三张SEM竖排缩得太小。
- 结果：主结果图占左侧，右侧上部放可编辑对比图、下部解释局限。图表明确单位、比较条件和选择性口径。
- 页标题必须说明科研内容，禁止“流程在上、证据在下”等制作旁白。
- 统一字体、配色、页边距和引用位置，不统一每页的内容容器数量。
- 不借用原稿标识、成果数据、人物、第三方模板资产；不把参考稿内容当成科学证据。

创新创业稿存在“添加标题内容”等模板占位页和不同领域素材，排除为设计范例。导入后个别旧稿出现字体/换行问题，不作为可照搬的版式。
