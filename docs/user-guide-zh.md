# 统一入口与交接

本仓库是人工审稿驱动的工作室，不是已完成的一键论文到PPT服务。A沉稳学术与C现代科技保留为候选，B不再用于新稿。旧文件均保留。

## 如何使用

1. 把PDF交给ChatGPT，说明汇报类型、语言、页数、时长。
2. 要求输出逐页大纲。每页包含标题、核心论点、来源页码/图号、拟用布局、待核实问题。
3. 把确认后的大纲写入 task.yaml，并将PDF放到Codex能读取的本地路径。通过附件下载/上传或实际复制文件交接；两个会话不会自动共享文件。
4. 在Codex中说：请按这个仓库的AGENTS.md和task.yaml制作PPT，先核对证据，大纲未经确认不要生成终稿，不调用付费API。
5. 逐页看预览，确认内容与视觉，再导出PPTX。图片只保证可移动替换；原生文本、框图及新增数据图分别检查编辑性。

/make-ppt 目前不是已安装的斜杠命令。等价自然语言是：按 Research PPT Studio 的 task.yaml 开始制作科研PPT。

## 本地任务检查

`./.venv312/Scripts/python.exe scripts/make_ppt.py task.yaml`

任务文件采用JSON语法，属于YAML 1.2的合法子集，可无需新增依赖读取。检查不会自动批准大纲，不会调用API，也不会假装完成论文理解。它输出可执行的本地示例构建建议；真实论文仍由Codex按交接内容执行。

## 版式选择

背景用问题递进或现象对照；研究内容用任务分解；路线用阶段与方法对应；机制用中心关系及证据标注；结果用主图和辅助对比；总结区分发现、局限与下一步。统一字体配色与边距，避免所有页固定三栏。
